-----------------------------------------------------------------------------------
SECTION A: READABLE SOURCE & HIGHER-LEVEL ENGINE LIBRARIES
-----------------------------------------------------------------------------------
Used for analyzing script logic, parsing ASCII/AST records, and generating DAG graphs.

1. Mutagen (C# / CLI Bridge)
   * Domain: High-level record generation, AST script parsing, and declarative mod edits.
   * Role in System: Generates strongly-typed C#/Rust intermediate representations of 
     records for KaDag without executing Papyrus code inside the game thread.

2. LOOT / libloadorder / esplugin (Rust)
   * Domain: ASCII load order evaluation and topological dependency graph sorting.
   * Role in System: Powering the KaDag DAG matrix, reading `.esp`/`.esm`/`.esl` header 
     flags (0xFE light slots), and sorting master constraints in sub-milliseconds.

3. Champollion / PEX Decompiler (C++ / Rust Port)
   * Domain: Reads compiled Papyrus byte-code (`.pex`) and reconstructs human-readable 
     Source Papyrus Scripting (`.psc`).
   * Role in System: Live inspection of active thread stacks identified by Canary Redux. 
     When a thread locks, it decompiles the offending `.pex` on-the-fly to pin-point 
     the exact source function call.

-----------------------------------------------------------------------------------
SECTION B: RAW BINARY, MEMORY INTERCEPT, & CRASH STACK LIBRARIES
-----------------------------------------------------------------------------------
Used for zero-copy memory reads, byte-level save-game slice manipulation, and 
out-of-process C++ thread stack walking.

1. rust-minidump / minidump-stackwalk (Rust)
   * Domain: Native Windows `.dmp` crash log parser and stack walker.
   * Role in System: Parses native Fallout 4 crash dumps asynchronously. When FO4 
     CTDs, minidump extracts the exact faulting C++ memory address, loaded DLL, 
     and instruction pointer without needing a debugger attached.

2. zlib-ng + flate2 (C++ / Rust Bindings)
   * Domain: Zero-copy raw binary stream decompression.
   * Role in System: Reads compressed chunks inside FO4 `.fos` save files in memory. 
     Decompresses save header byte slices in <1ms to inspect active script heaps.

3. zerocopy + byteorder (Rust)
   * Domain: Direct casting of raw C++ memory pointers into Rust structs.
   * Role in System: Consumes the Shared Memory Ring Buffer (mmap) written by `vprobe.dll`. 
     Converts raw engine C++ memory slices to Rust data without allocations.

4. Capstone Engine (C++ / Python)
   * Domain: Low-level disassembly framework.
   * Role in System: Disassembles engine memory addresses around `SaveGame()` and 
     `PapyrusVM` vtables dynamically, avoiding hardcoded static offsets across FO4 updates.
