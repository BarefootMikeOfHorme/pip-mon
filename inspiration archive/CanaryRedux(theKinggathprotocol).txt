===================================================================================
      CANARY REDUX (THE KINGGATH PROTOCOL) - SYSTEM SPECIFICATION
===================================================================================

1. PROJECT HONOUR & NOMENCLATURE
-----------------------------------------------------------------------------------
- Legacy Mod: Kinggath's Canary Save File Monitor (Papyrus-based passive check).
- New Engine: Canary Redux / The Kinggath Protocol (CKP).
- Core Objective: Upgrade from passive script checks to an active, zero-overhead 
  native C++ engine hook paired with an external Rust/Python repair daemon.


2. ARCHITECTURAL DUAL-LAYER DESIGN
-----------------------------------------------------------------------------------
[LAYER A: Native C++ Engine Hook (In-Game Steering)]
  - Operates as a lightweight F4SE / SKSE C++ plugin (.dll).
  - 0% Papyrus Script Overhead: Runs outside the Papyrus Virtual Machine.
  - Pre-Save Lock Valve (Quiescent Save Guarantee):
    * Intercepts native `SaveGame()` engine events.
    * Queries `PapyrusVM::GetNumPendingEvents()`.
    * If active stack threads exceed safety thresholds (>50 queued events),
      holds save execution thread up to 1500ms to allow script queues to unwind.
    * Flushes VM state to guarantee a zero-stack "quiescent" save on disk.
  - Ring Buffer IPC Telemetry:
    * Streams thread counts, FormID allocations, and engine load flags over 
      Shared Memory (mmap) / Named Pipe directly to the external daemon.

[LAYER B: External Daemon & Offline Repair (Out-of-Process)]
  - Executed inside the KaDag / PIP-MON workspace pipeline.
  - Asynchronous Post-Save Inspection:
    * Immediately parses newly written `.fos` save headers asynchronously.
    * Validates save chunk markers and inspects the baked `plugins.txt` array.
  - Automated Repair Strategies (Active Sanity Engine):
    1. FormID Remapping: Automatically shifts orphaned FormID prefixes if 
       plugins were reordered or removed, preventing instant CTD on load.
    2. Unattached Instance Pruning: Surgically purges dead script instances 
       pointing to missing base forms (`FormID == 0x00000000`).
    3. Heap Sanitization: Truncates bloated script arrays (>10,000 indices) 
       and re-calculates chunk byte counts.


3. REAL-TIME TELEMETRY WIDGETS (TUI / WORKSPACE INTEGRATION)
-----------------------------------------------------------------------------------
Canary Redux populates live indicators in the main TUI Header:

+---------------------------------------------------------------------------------+
| CANARY REDUX: 🟢 QUIESCENT | VM Stack: 0/128 | Save Readiness: [ SECURE ]       |
| Last Save Check: Save_104.fos (Passed 0ms) | Active Remaps: 0 | Orphans: 0       |
+---------------------------------------------------------------------------------+


4. SAFE RECOVERY & BACKUP PIPELINE
-----------------------------------------------------------------------------------
1. Trigger Save -> C++ Hook applies Pre-Save Lock until VM queue = 0.
2. File written -> C++ Hook sends IPC alert `SaveComplete: Save_105.fos`.
3. Daemon inspects `Save_105.fos`:
   - [PASS] -> Marked `[ SECURE ]` in TUI.
   - [FAIL] -> Quarantined immediately. Daemon applies Repair Strategies 1-3,
               generates `Save_105_Repaired.fos`, creates timestamped backup 
               `Save_105.fos.bak`, and alerts user prior to next game load.
